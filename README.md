# Indie-Демо

Платформа для инди-разработчиков, где можно выкладывать демо-версии игр и общаться в чате.

## Функционал

- Регистрация и авторизация
- Загрузка демо-версий игр (ZIP, RAR, EXE)
- Скачивание игр с счётчиком скачиваний
- Админ-панель для модерации
- Живой чат с автоподгрузкой
- Адаптивный дизайн

## Стек технологий

- **Backend:** Flask, SQLAlchemy
- **Database:** SQLite (локально) / PostgreSQL (в продакшене)
- **Frontend:** HTML, CSS, JavaScript
- **Auth:** bcrypt (хеширование паролей)
